# My LAN Dashboard Frontend

## Overview
My LAN Dashboard is a web application designed for mapping devices on your home network. It provides an intuitive interface for scanning the network, viewing device details, and managing device information.

## Features
- **Network Scanning**: Manually scan your network to detect connected devices and their MAC addresses.
- **Device Management**: Store and manage information about devices, including vendor, hostname, and last access date.
- **Custom Fields**: Add user-defined fields for IP release type, connection type, and device type.
- **User-Friendly Interface**: Easy-to-use web interface for interacting with the application.

## Getting Started

### Prerequisites
- Node.js and npm installed on your machine.

### Installation
1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the frontend directory:
   ```
   cd my-lan-dashboard/frontend
   ```
3. Install the dependencies:
   ```
   npm install
   ```

### Running the Application
To start the frontend application, run:
```
npm start
```
This will launch the application in your default web browser.

### API Integration
The frontend communicates with the backend API to fetch and manage device data. Ensure that the backend service is running to enable full functionality.
